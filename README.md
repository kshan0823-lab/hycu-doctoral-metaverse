# HYCU 부동산대학원 박사논문 연구캠퍼스

HYCU 부동산대학원 럭셔리 3D 연구캠퍼스의 외부 연결 없는 전체 공간 시연판입니다. 기존 19개 연구 구역에 웰니스 공간, 박사연구실 05, 개인 휴게실 05, 교수 전용 84㎡ 럭셔리 오피스텔, 담당자별 개인 화장실·샤워장 6곳을 더해 총 29개 공간으로 구성했습니다. 실제 학교 서비스나 실제 논문 저장소가 아니라, 가상 자료로 이동·착석·열람·논문지도를 확인하는 첫 단계입니다.

## 바로 실행하기

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173`을 열고 입장 신청을 합니다. 교수·연구생은 6명 중 한 명을 선택하고 학번·교직원번호를 입력하며, 방문자는 이름·휴대폰 번호·방문목적을 입력합니다. 관리자 페이지는 비밀번호 `4747`을 입력한 뒤 신청자를 승인하고, 승인된 사람만 캠퍼스에 입장합니다.

## 확인할 흐름

1. 교수·연구생 또는 방문자 입장 신청
2. `관리자 페이지`에서 비밀번호 `4747` 입력
3. 신청자 확인 후 승인 또는 거절
4. 승인된 신청자가 남자 5종·여자 5종 사람 이모지 중 내 캐릭터를 선택하고 캠퍼스 입장
5. 왼쪽 29개 공간 메뉴 또는 3D 공간을 눌러 이동
6. `WASD`·방향키 또는 3D 바닥을 마우스로 클릭·끌어서 아바타 이동
7. 3D 화면에서 왼쪽 마우스를 누르고 좌우·위아래로 드래그하면 바닥 위에서 화면 방향 이동
8. 3D 화면에서 마우스 휠을 위로 올리면 확대하고 아래로 내리면 축소
9. 강의장·라운지·도서관에서 좌석 선택
10. 휘트니스 센터에서 중앙 운동 공간과 원형 러닝트랙 확인
11. 교수 전용 84㎡ 공간에서 거실·다이닝·간이주방·휴식존 확인
12. 담당자별 개인 화장실·샤워장 6곳에서 이름·시설 구성 확인
13. 자료 패널에서 가상 자료 검색 및 열기
14. 김승환 지도교수와 문국찬·윤금순·김태영·김두호·심의준 연구생 이름 확인
15. 담당교수 연구실에서 논문지도 의견 저장
16. 상단의 `2D 접근 화면`에서 같은 공간과 자료 흐름 확인
17. 3D 화면 왼쪽 상단의 `알림터 통합게시판`에서 공지 제목을 눌러 상세 내용을 확인
18. 교수 계정에서 `+ 새 공지`로 글을 작성하고 굵게·기울임·밑줄·제목·글머리표·번호 목록·정렬·링크를 적용한 뒤 저장
19. 저장한 공지의 상세 화면에서 수정·삭제 처리. 저장·수정·삭제를 확인하면 상세창만 닫히고 알림터 게시판은 그대로 남아 목록만 갱신됩니다.
20. 알림터의 `2) 학습자료 랜딩페이지` 항목을 클릭해 학습자료 화면으로 이동
21. 학습자료 화면 상단의 `3D 가상공간으로 돌아가기` 블록을 눌러 연구캠퍼스로 복귀
22. 알림터·현재 입장자 위치·캠퍼스 출결 현황 상자의 `접기`·`펼치기` 버튼으로 3D 화면을 넓게 사용
23. 승인 후 `현재 등교인원`에 기록되고, 3D 화면의 `조퇴인원` 또는 `하교인원` 블록을 누르면 이용 종료

관리자 신청 카드에서는 `승인`, `거절`, `방문목적 다시 요청`, `보류`, `신청 내역 삭제` 블록을 각각 클릭할 수 있습니다. 방문목적 재기록 요청을 받은 방문자는 목적을 다시 입력해 재신청할 수 있습니다.

교수 연구실과 연구생 연구실은 담당자 승인 전에는 입장할 수 없습니다. 입장 대화창에서 `신청`을 보내고 담당자가 `승인`을 입력하면 해당 공간으로 들어갈 수 있습니다. 교수 오피스텔, 개인 휴게실, 개인 화장실·샤워실은 담당자 본인 외 입장을 제한합니다.

3D 화면에는 입장자 위치 목록과 이모지 머리 위 이름표가 함께 표시됩니다.

알림터 통합게시판은 캠퍼스 3D 화면의 왼쪽 상단에 표시됩니다. 모든 입장자는 공지 제목과 내용을 읽을 수 있으며, 과목운영책임 교수로 입장한 경우에만 새 공지 작성·수정·삭제와 상단 고정을 사용할 수 있습니다. 공지 내용은 이 브라우저의 시연 기록에 저장됩니다.

출결 현황은 승인된 사람이 실제로 캠퍼스에 입장할 때 `현재 등교인원`으로 집계됩니다. 입장자는 3D 공간의 출결 블록에서 `조퇴인원` 또는 `하교인원`을 선택할 때까지 공간에 머물며, 선택하면 3D 공간을 나가고 관리자 페이지의 해당 인원 집계에 반영됩니다.

## 연결 전 상태

입장 신청과 관리자 승인 정보는 현재 시연을 위해 사용하는 브라우저 안에만 저장됩니다. 실제 로그인·학교 SSO·LMS 출석, 서버 기반 다중 접속·권한, 실제 파일 저장, 음성·영상·화면 공유, 자동 번역, VR, 40명 부하 시험은 연결 설정과 별도 검증이 필요합니다. 화면과 [기능 현황](docs/FEATURE_STATUS.md)에 이 상태를 표시했습니다.
