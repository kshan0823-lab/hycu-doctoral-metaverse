# 기능 현황

| 항목 | 상태 | 시연에서 확인하는 방법 |
|---|---|---|
| 총 29개 3D 공간 | implemented | 왼쪽 공간 메뉴, 넓은 단층 3D 캠퍼스, 2D 접근 화면 |
| 웰니스 확장 구역 | demo-only | 대형 휘트니스 센터와 외부 원형 러닝트랙 |
| 박사연구생 05 연구실·개인 휴게실 05 | implemented | 연구실 05와 개인 휴게실 05 이동·공간 확인 |
| 교수 전용 84㎡ 럭셔리 오피스텔 | demo-only | 거실·다이닝·간이주방·휴식존과 6석 확인 |
| 교수·연구생 6명 입장 신청 | implemented | 과목운영책임 교수와 연구생 01~05 중 선택 후 학번·교직원번호 입력 |
| 방문자 입장 신청 | demo-only | 방문자 이름과 휴대폰 번호 입력 후 관리자 확인 대기 |
| 관리자 비밀번호 입장 | demo-only | `관리자 페이지`에서 비밀번호 `4747` 입력, 입력 중 문자는 `*`로 표시 |
| 관리자 승인·거절 화면 | demo-only | 비밀번호 확인 후 신청 상태 확인 및 승인·거절 |
| 관리자 보류·방문목적 재기록 요청 | demo-only | 신청 카드의 `보류` 또는 `방문목적 다시 요청` 블록 클릭 |
| 신청 내역 삭제 | demo-only | 신청 카드의 `신청 내역 삭제` 블록 클릭 후 확인 |
| 교수실·연구실 공간별 입장 신청 | demo-only | 입장 대화창에 `신청` 기록 후 담당자의 `승인` 입력 시 입장 |
| 교수 오피스텔·개인 휴게실·화장실·샤워실 독립 제한 | demo-only | 담당자 본인 외에는 공간별 접근 차단 |
| 입장 시 사람 이모지 선택 | implemented | 남자 5종·여자 5종 중 캐릭터를 선택하고 내 아바타로 이동 |
| 교수·연구생 이름 표시 | implemented | 김승환, 문국찬, 윤금순, 김태영, 김두호, 심의준 표시 |
| 입장자 위치·이름표·마우스 이동 | implemented | 이모지 머리 위 이름표, 위치 목록, 3D 바닥 클릭·끌기 이동 |
| 담당자별 개인 화장실·샤워장 6곳 | demo-only | 각 담당자 전용 표지, 변기·샤워부스·세면대·거울 표현 |
| 구역 이동·카메라 초기화 | implemented | 구역 선택, WASD/방향키, 우측 이동 버튼 |
| 3D 전체 공간 확대·축소 | implemented | 3D 화면 위에서 마우스 휠 위·아래 조작 |
| 3D 화면 방향 이동·바닥 아래 차단 | implemented | 3D 화면에서 왼쪽 마우스를 누르고 좌우·위아래로 드래그, 바닥 아래 진입 방지 |
| 좌석 선택·일어서기 | demo-only | 강의장·라운지·도서관 등에서 좌석 선택 |
| 가상 논문·강의자료 열람 | demo-only | 자료 열람 패널에서 검색·열기 |
| 논문 버전·지도 일정·지도 의견 | demo-only | 교수실 → 논문지도 → 시연 기록 저장 |
| 알림터 통합게시판 목록·상세 열람 | implemented | 3D 화면 왼쪽 상단 게시판에서 제목 클릭 |
| 알림터 공지 등록·수정·삭제 | demo-only | 과목운영책임 교수 입장 후 `+ 새 공지`, 상세 화면의 수정·삭제 |
| 알림터 서식 편집 | demo-only | 굵게·기울임·밑줄·제목·글머리표·번호 목록·정렬·링크 |
| 알림터·현재 입장자 위치 상자 접기·펼치기 | implemented | 각 상자 오른쪽의 `접기` 또는 `펼치기` 버튼 |
| 승인 후 현재 등교·조퇴·하교 인원 집계 | demo-only | 3D 화면 출결 블록과 관리자 페이지 출결 인원 집계 |
| 입장자 조퇴·하교 처리 | demo-only | 본인이 `조퇴인원` 또는 `하교인원` 블록을 누르면 3D 공간 종료 |
| 한글 UI·2D 대체 화면 | implemented | 상단 2D 접근 화면 버튼 |
| 실제 로그인·학교 SSO·LMS | not-implemented | 학교 연동 승인과 별도 개발 필요 |
| 서버 기반 다중 접속·실제 권한 | needs-configuration | API·방 서버·계정 데이터 필요 |
| 음성·영상·화면 공유 | needs-configuration | 미디어 서비스와 서버 발급 권한 필요 |
| 자동 번역·동시통역 | not-implemented | 번역 서비스 연결 필요 |
| VR 헤드셋 | not-implemented | WebXR 기기별 별도 검증 필요 |
| 40명 부하·60분 수업 리허설 | not-implemented | 실제 서버와 여러 기기에서 별도 측정 필요 |

입장 신청·관리자 승인 정보는 현재 브라우저 내부 저장소에만 보관되는 시연용 기능이다. 실제 운영에서는 관리자 계정, 서버 저장, 본인 확인, 개인정보 보호 정책이 추가로 필요하다.
